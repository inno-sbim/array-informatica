 Breve spiegazione teorica / Brief Theory

Italiano:

Un array è una struttura che permette di memorizzare più valori dello stesso tipo con un solo nome.

Ogni valore ha un indice, che parte da 0.

Gli array permettono di gestire dati in sequenza, come voti, numeri o misure.

English:

An array is a structure that stores multiple values of the same type under a single name.

Each value has an index, starting from 0.

Arrays allow managing data in sequence, such as grades, numbers, or measurements.

 Obiettivi didattici / Learning Objectives

Italiano:

Imparare a dichiarare e usare un array in C.

Capire come inserire, memorizzare e leggere i dati.

Saper fare elaborazioni semplici (somma, media) sui dati di un array.

English:

Learn how to declare and use an array in C.

Understand how to input, store, and read data.

Perform simple calculations (sum, average) on array data.

 Spiegazione degli esempi / Code Explanation

Italiano:

Inserimento dei dati: si usano cicli (while) per far inserire più valori senza ripetere codice.

Elaborazione: si calcola la somma dei valori e poi la media.

Output: si stampano tutti i valori e il risultato finale.

English:

Data input: loops (while) are used to enter multiple values without repeating code.

Processing: the sum of values is calculated, then the average.

Output: all values and the final result are printed.
